# Task game — หน้าเว็บ

PWA สำหรับใช้ส่วนตัว แสดงงานจาก TickTick เป็นเควสพร้อมชั้นเกม

repo นี้มีแค่ไฟล์หน้าเว็บ (static) เท่านั้น — โค้ดหลังบ้านและเอกสารออกแบบ
อยู่แยกต่างหากและไม่เผยแพร่ เพราะมีข้อมูลงานส่วนตัว

## ใช้งาน

เปิดหน้าเว็บ แล้วใส่สองอย่างในครั้งแรก:

- **Web app URL** ของ Apps Script (ลงท้าย `/exec`)
- **Token** ที่ได้จากฟังก์ชัน `step6_setupApi`

ทั้งสองค่าเก็บใน `localStorage` ของเครื่องนั้น ไม่ได้ฝังในไฟล์ใด ๆ ใน repo นี้

## ไฟล์

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | ทั้งแอปในไฟล์เดียว ไม่มีขั้นตอน build |
| `sw.js` | service worker — แคชเฉพาะเปลือกแอป ไม่แคชข้อมูลจาก API |
| `manifest.webmanifest` | ทำให้ติดตั้งลงหน้าจอได้ |
| `AGENTS.md` | สัญญาข้อมูลสำหรับผู้ช่วย AI ตัวอื่นที่แตะ TickTick ชุดเดียวกัน |
| `docs/skill-snippet.md` | ข้อความพร้อมวางลง skill ของผู้ช่วยในห้องแชท |

## แท็กบริบท — พลังงาน / สถานที่ / ระยะเวลา

สามมิตินี้ไม่มีในสคีมาของงาน (มีแค่ความสำคัญ กำหนดส่ง ทักษะ ขั้นย่อย)
จึงอ่านจาก **แท็กใน TickTick** ที่ backend ส่งมาเป็น edge `tagged` ในกราฟอยู่แล้ว
ไม่ต้องแก้ฝั่งเซิร์ฟเวอร์ แลกกับข้อจำกัดว่าแก้ค่าได้จากในแอป TickTick เท่านั้น

| แท็ก | ความหมาย |
|---|---|
| `⚡สูง` `⚡กลาง` `⚡ต่ำ` | ระดับพลังงานที่ต้องใช้ |
| `📍บ้าน` `📍ศิริราช` | สถานที่ — ตั้งชื่ออะไรก็ได้หลัง 📍 |
| `⏱15` `⏱30` `⏱90` | เวลาที่คาดว่าจะใช้ หน่วยนาที |

แท็กเดิมนับให้อัตโนมัติ: `🎯 ต้องต่อเนื่อง` = พลังงานสูง · `🔄 แทรกได้` = พลังงานต่ำ
ถ้ามีแท็ก `⚡` ชัด ๆ อยู่ด้วย อันที่ติดเองชนะเสมอ

variation selector (U+FE0F) ถูกตัดก่อนเทียบ `⏱️30` กับ `⏱30` จึงเป็นแท็กเดียวกัน

## มุมมอง

`วันนี้` `จัดลำดับ` (Eisenhower) `จัดกลุ่ม` `ไทม์ไลน์` `ผังความคิด` `ทั้งหมด`

ทุกมุมมองอ่านข้อมูลผ่าน `visibleQuests()` ตัวเดียว — แถบกรองชุดเดียวจึงคุมได้ทั้งแอป
ห้าม renderer อ่าน `STATE.quests` ตรง ๆ ไม่งั้นจะเรียงไม่ตรงกันข้ามหน้า

**งบเวลา** บนหัวหน้า "วันนี้" และ "จัดกลุ่ม" เอาเวรกับนัดจากปฏิทินมาหักออกก่อน
แล้วค่อยเทียบกับเวลารวมของงานที่ติดแท็ก ⏱ ไว้ — งานจะจัดเป็นก้อนได้จริงก็ต่อเมื่อ
วันนั้นเหลือเวลาพอ ตัวเลขนี้ไม่ผ่านตัวกรอง เพราะเป็นความจริงของวัน ไม่ใช่มุมมองที่เลือกดู

เวรที่ข้ามเที่ยงคืนถูกตัดแบ่งตามวัน (16:30–00:00 กินสองวัน, 2:30–8:30 อยู่วันเดียว)
เวรที่ `startDate` เท่ากับ `dueDate` ถือว่าไม่รู้ว่ากินเวลาเท่าไร — นับหัวไว้เฉย ๆ ไม่เดาชั่วโมง
เวลาว่างประมาณจากวันตื่น 16 ชม. (`AWAKE_MIN`) ไม่ใช่ตารางเวลาจริง

**โหมดฉุกเฉิน** (🚨 บนแถบบน) พักตัวกรองทุกตัว เหลือเฉพาะงานเลยกำหนด ครบวันนี้
หรือสำคัญมาก แล้วเรียงตามความสำคัญเสมอ — ตัวกรองที่ตั้งค้างไว้ตอนเช้า
ไม่ควรมาบังงานด่วนตอนบ่าย

## หมายเหตุ

หน้านี้ debug จากคอนโซลได้: `TG.state = {...}; TG.render()`

สีในไทม์ไลน์แทน **ระดับความสำคัญ** ไม่ใช่ทักษะ — เจ็ดสีแยกไม่ออกจริงเมื่อตาบอดสี
จึงแยกทักษะด้วยหัวข้อกลุ่มเป็นข้อความแทน

ด้วยเหตุผลเดียวกัน มิติบริบทที่เพิ่มมาใช้ **ไอคอนกับตัวอักษร** (⚡ 📍 ⏱) ไม่ใช่สี
พาเลตต์นี้มีสีหมวดหมู่ที่แยกออกจริงแค่สามช่อง เติมอีกสามมิติเป็นสีแล้วอ่านไม่ออกทั้งหมด
